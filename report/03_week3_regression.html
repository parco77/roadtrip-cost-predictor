5.1 The model

Because several columns are useful, this is multiple linear regression:

Ŷ = w1X1 + w2X2 + … + wkXk + c

DroppedReason
passengers, departure_hourCorrelation with the target is ≈ 0 (−0.05 and −0.03). They add noise, not signal.

All one-hot columnsRank deficiency — see the box below.

Why dropping the one-hot columns was necessary, not lazy

In this dataset every route is a fixed pair. Delhi only ever goes to Jaipur, so the column start_city_Delhi and the column destination_city_Jaipur contain identical values in every row.

That makes the design matrix rank-deficient: infinitely many different weight combinations produce the exact same predictions. sklearn silently picks one of them using the pseudo-inverse; gradient descent, starting from zeros and walking downhill, would converge on a different one. Both would be equally correct and the two weight vectors would look completely different.

Since the entire point of Week 3 is to compare the two sets of parameters, keeping those columns would have made a correct result look broken. Dropping them keeps the comparison meaningful. This is the single most likely thing to be probed in a viva, and the answer is “identical columns → infinitely many solutions → the comparison becomes meaningless”.

Final matrices: X shape (1129, 6), values 0.000–1.000; y shape (1129,), ₹688.79–₹4,271.82.

5.4 Part B (warm-up) — one feature, by hand

Before doing six features at once, the classic y = mx + c case, using distance_km alone. The three steps of gradient descent:

1. Loss function — Mean Squared Error, i.e. how wrong the current line is:

L(m, c) = (1/n) ∑ ( Yi − (mXi + c) )²

2. Gradients — the direction that increases the loss:

∂L/∂m = (2/n) ∑ Xi · errori      ∂L/∂c = (2/n) ∑ errori      where error = Ŷ − Y

3. Update rule — step in the opposite direction; that is the “descent”:

m ← m − lr · ∂L/∂m      c ← c − lr · ∂L/∂c

5.5 Part B — all six features

Extending m, c to w, b: one weight per feature plus a single bias.

Ŷ = Xw + b      L(w, b) = (1/n) ∑ (Ŷi − Yi)²
∂L/∂wj = (2/n) ∑i Xij · errori      ∂L/∂b = (2/n) ∑i errori

All six gradients are computed in a single matrix operation, X.T @ error, rather than one Python variable per feature. This is the vectorised form — it is both far faster and closer to the mathematics.

def gradient_descent(X, Y, lr=0.2, epochs=50000, tol=1e-8):
    n, k = X.shape
    w = np.zeros(k)          # initial guess: all weights zero
    b = 0.0
    loss_history = []
    for i in range(epochs):
        Y_pred = X.dot(w) + b                    # current prediction
        error  = Y_pred - Y                      # predicted - actual
        loss   = (1 / n) * np.sum(error ** 2)    # MSE
        loss_history.append(loss)

        dw = (2 / n) * X.T.dot(error)            # gradient for every weight at once
        db = (2 / n) * np.sum(error)             # gradient for the bias

        w = w - lr * dw                          # update
        b = b - lr * db

        if i > 0 and abs(loss_history[-2] - loss_history[-1]) < tol:
            break                                # loss has gone flat: converged
    return w, b, loss_history, i + 1

Why they must match — the answer to expect to give

The MSE loss for linear regression is a convex function — a bowl with exactly one minimum and no local minima to get stuck in. sklearn jumps straight to the bottom by solving the normal equations algebraically. Gradient descent walks down to the same bottom one step at a time. Given a sensible learning rate and enough epochs, both must land in the same place, because there is nowhere else to land.

The largest disagreement on any parameter is 4 paise, against coefficients in the hundreds and thousands.

5.9 Week 3 conclusion

Do the sklearn parameters and the gradient-descent parameters match? Yes — to within 0.03%, for both the single-feature warm-up and the six-feature model. Predictions never differ by more than ₹0.011 across all 1,129 trips, R² is identical to six decimal places, and RMSE and MAE agree to three.

Week 3 ended with R² = 0.992841 and a note that the remaining 0.7% looked “structural”. That number was suspiciously high — which is what sent Week 4 looking for the reason.
